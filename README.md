# TanJ1ns — Портфолио разработчика (React + Vite + Node.js + SQLite)

Минималистичная витрина проектов с админ-панелью для публикации сайтов, веб-приложений, Telegram-ботов, Mini Apps и утилит.

## Возможности
- **Универсальный каталог проектов:** 6 категорий (`Сайты`, `Веб-приложения`, `Telegram-боты`, `Mini Apps`, `Приложения`, `Автоматизация`), живой поиск по названиям и стеку, модальное окно проекта с галереей скриншотов.
- **Админ-панель (`/admin`):** добавление/редактирование/удаление любых проектов, загрузка скриншотов с ПК, управление профилем, стеком и ссылками на фриланс-биржи (Kwork, FL.ru, GitHub, Telegram).
- **Готово к деплою в РФ:** единый порт Node.js + SQLite (без зарубежных SaaS-зависимостей), подготовлены `Dockerfile` и `amvera.yml` для развёртывания на **Amvera Cloud**, **Timeweb Cloud Apps** или любом VPS в России (стабильный доступ с российских IP без VPN).

## Локальный запуск

```bash
npm install
npm run build
npm start
```

Сайт откроется на `http://localhost:4000`.
Вход в админ-панель (`/admin`): `admin@tanj1ns.dev` / `admin12345` *(при деплое задайте свои `ADMIN_EMAIL` и `ADMIN_PASSWORD` в переменных окружения)*.

## Хостинг с доступом из РФ
- **Amvera Cloud (amvera.ru):** подключите GitHub-репозиторий — конфиг `amvera.yml` уже готов, база SQLite и загруженные скриншоты сохраняются в постоянном хранилище `/data` (переменная `DATA_DIR=/data`).
- **Timeweb Cloud Apps / VPS в РФ:** деплой через готовый `Dockerfile` с примонтированным томом `/data`.
