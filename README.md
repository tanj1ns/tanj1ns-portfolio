# TanJ1ns — Портфолио разработчика (React + Vite + Node.js + SQLite)

Минималистичная витрина проектов с локальной и серверной админ-панелью для публикации сайтов, веб-приложений, Telegram-ботов, Mini Apps и утилит.

- **Живое портфолио (GitHub Pages, 0 ₽):** https://tanj1ns.github.io/tanj1ns-portfolio/
- **Живое демо проекта №1 («АПЕКС АВТО»):** https://tanj1ns.github.io/apex-auto-service/

## Возможности
- **Универсальный каталог проектов:** 6 категорий (`Сайты`, `Веб-приложения`, `Telegram-боты`, `Mini Apps`, `Приложения`, `Автоматизация`), живой поиск по названиям и стеку, модальное окно проекта с галереей скриншотов.
- **Админ-панель (`/admin`):** скрыта от гостей в шапке сайта; добавление/редактирование/удаление любых проектов, загрузка скриншотов с ПК, управление профилем, стеком и ссылками на фриланс-биржи (Kwork, GitHub, Email, Telegram).
- **Бесплатная публикация на GitHub Pages:** при любом изменении в локальной админке автоматически обновляется `public/portfolio-data.json`, а команда `npm run publish` публикует обновлённую витрину в ветку `gh-pages`.
- **Готово к серверному деплою в РФ:** также подготовлены `Dockerfile` и `amvera.yml` для развёртывания на Amvera Cloud, Timeweb Cloud Apps или любом VPS в России (с сохранением SQLite в `/data`).

## Локальный запуск и обновление витрины

```bash
npm install
npm run build
npm start
```

- Локальный сайт: `http://localhost:4000`
- Вход в админ-панель (`http://localhost:4000/admin`): `admin@tanj1ns.dev` / `admin12345` *(при деплое на сервер задайте свои `ADMIN_EMAIL` и `ADMIN_PASSWORD` в переменных окружения)*.
- **Опубликовать обновления на бесплатный GitHub Pages:**
  ```bash
  npm run publish
  ```
